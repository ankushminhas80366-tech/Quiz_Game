# Quiz Game 🎮

A simple interactive command-line quiz game written in Python. Test your knowledge with questions about India, general knowledge, science, and technology!

## Features ✨

- 20 carefully curated multiple-choice questions
- Topics include:
  - Indian politics, geography, and culture
  - National symbols of India
  - Basic science and technology
  - General knowledge
- Progressive scoring system (earn 1000 points for each correct answer)
- Immediate feedback on answers
- Clean and simple terminal interface
- Error handling for invalid inputs

## How to Play 🎮

1. Run the game
2. Press `1` to start or `0` to quit
3. Read each question carefully
4. Enter the number (1-4) corresponding to your answer
5. Keep answering correctly to increase your score!
6. The game ends if you get a wrong answer or finish all questions

## Requirements 📦

- Python 3.x (no external libraries required)

## Installation & Running 🚀

1. Clone this repository:
```bash
git clone https://github.com/ankushminhas80366-tech/Quiz_Game.git
cd Quiz_Game
```

2. Run the game:
```bash
python main.py
```

or

```bash
python3 main.py
```
